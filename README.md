# Projet MediaTek86

### Présentation
Ce projet consiste en la création d'une application de gestion pour l'organisation MediaTek86. Elle permet la gestion du personnel, des services associés et le suivi des absences.

### Fonctionnalités principales
* **Gestion du personnel :** Ajout, modification et suppression de collaborateurs.
* **Gestion des services :** Liaison entre les employés et leurs services respectifs.
* **Suivi des absences :** Consultation de l'historique des absences par personnel.
* **Authentification :** Accès sécurisé à l'application via un compte responsable.

### Architecture technique
* **Langage :** C# / WinForms
* **Base de données :** MySQL
* **Pattern :** MVC (Modèle-Vue-Contrôleur)
